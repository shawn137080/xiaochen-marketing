# 选题生成

1. 读 `vault/00-定位/账号定位.md`。
2. 种子是对标笔记的话，读它的数据和拆解；是热点链接的话，用 agent-reach 读原文。
3. 用公式 **人群 × 场景 × 工具 × 结果** 发散出 3–5 个方向，然后用四关筛选（人群 / 结果 / 验证 / 差异，标准见 `xhs-radar` skill 第 4 步），只留通过的。
4. 先 `ls vault/40-选题库` 查重。相近的选题就补充到已有文件里，不要新建。
5. 按 `vault/_templates/选题.md` 写入 `vault/40-选题库/<选题短名>.md`。要求：
   - 3 个备选标题，每个 ≤ 20 字（小红书标题上限），至少一个带具体数字或结果。
   - 写明封面思路（大字文案 + 画面）。
   - 内容骨架 4–6 步，第一步必须是钩子。
   - `推荐分` 和 `来源笔记`/`来源热点` 要填好。
6. 加入看板：`npm run xhs -- kanban-add 待选 "[[选题短名]]"`
7. 在 chat 里简短告诉用户新增了哪些选题、各自推荐分多少。

# AI 辅助写稿

AI 只出初稿和备选，最终由用户改。所以要多给备选，少替用户做决定。

1. 读 `vault/00-定位/账号定位.md`（人设口吻、不做的内容）和对应的选题文件，以及选题里链接的对标笔记拆解。
2. 问一次用户（已经说过就不问）：做图文还是视频？有没有自己的实测结果、截图、亲身经历？**真实实测细节是这个账号的核心，没有就在稿里留 `【待补：实测结果】`，不要编。**
3. 按 `vault/_templates/稿件.md` 写到 `vault/50-稿件/<选题短名>.md`：
   - **标题** 5 个，每个 ≤ 20 字，各用不同的公式（数字结果 / 人群点名 / 反常识 / 对比 / 提问）。
   - **封面文案**：≤ 12 字大字，加一行副标题。
   - **正文**（图文）：≤ 800 字，口语化，短段落，emoji 适量。首段 2 行内说清"你能得到什么"。按步骤写，结尾抛一个具体问题引导评论。
   - **口播稿**（视频）：前 3 秒必须是钩子。标出【画面】提示，60–90 秒的量。
   - **话题标签**：5–8 个，大词和长尾词搭配。
4. **去 AI 味**：不要"在这个快节奏的时代""总而言之""赋能""助力"这类词。少用排比，不要每段都总结。像朋友发消息一样说话。英文工具名保留英文。
5. 选题文件里加 `稿件: "[[50-稿件/<选题短名>]]"`。看板上把卡片从「已选」挪到「写稿」：直接编辑 `vault/选题看板.md`，然后运行 `npm run xhs -- kanban-sync`。

# 使用说明

## 一次性设置
1. 把这个仓库 clone 到本地，Obsidian →「打开文件夹作为仓库」→ 选择 `vault/` 文件夹。
2. 设置 → 第三方插件 → 关闭安全模式，然后安装并启用这三个插件：**Dataview**、**Kanban**、**Obsidian Git**（vault 里已经预设好启用列表）。
3. Obsidian Git 设置里开启 *Auto pull interval*（比如 10 分钟）和 *Auto commit-and-sync*。
   vault 是仓库的子文件夹，桌面端 git 会自动找到上层仓库；手机端暂不支持。
4. 打开 [[00-定位/账号定位]]，给每个对标账号补上「主页链接」。

## 每天怎么用
| 你在 Claude chat 里说 | 会发生什么 |
|---|---|
| 「跑一下今天的选题雷达」 | 抓对标账号和关键词 → 打分 → 扫热点 → 拆解高分笔记 → 生成 5–8 个选题放进看板「待选」 |
| 「拆解这篇 <链接>」 | 拆标题、钩子、结构、评论区，并给出 3 个改写角度 |
| 「这个能做成选题吗：<想法/链接>」 | 扩写成选题，存进选题库 |
| 「帮我写 <选题名>」 | 按人设出标题、封面文案、正文或口播稿 |

然后在 Obsidian 里：
- [[首页]]：今日推荐、高分笔记、正在涨的笔记、对标账号动态。
- [[选题看板]]：拖动卡片推进流程：待选 → 已选 → 写稿 → 待录 → 待剪 → 已发布 → 复盘。

## 选题分怎么算（0–100）
| 权重 | 指标 | 含义 |
|---|---|---|
| 35% | 超常倍数 | 这篇互动 ÷ 这个账号其他笔记的中位数。**最重要**：说明是选题本身火了，而不是靠账号权重 |
| 20% | 赞粉比 | 互动 ÷ 粉丝数。低粉也能爆，说明选题好 |
| 20% | 量级 | 互动的绝对值 |
| 15% | 藏赞比 | 收藏比点赞多，是干货型，长尾流量好 |
| 10% | 评赞比 | 讨论度高，评论区里有需求可挖 |

越新的笔记权重越高，但老笔记最多只打 6 折，因为常青选题依然值得做。
权重可以在仓库根目录的 `xhs.config.json` → `scoring` 里调。

## 文件夹
- `00-定位`：人设、人群、关键词、对标账号。所有 AI 判断都以这里为准。
- `10-对标账号`：每个账号一页，自动更新粉丝和爆款数。
- `20-对标笔记`：抓到的笔记，带数据和拆解。
- `30-热点`：每日热点扫描结果。
- `40-选题库` / `50-稿件` / `60-复盘`
- `_data/raw`：原始抓取数据，已在搜索中隐藏。

# 🎯 小红书工作台

**每日流程**：在 Claude 里说「跑一下今天的选题雷达」→ 看下面的「今日推荐选题」→ 在 [[选题看板]] 把想做的拖到「已选」。

## 今日推荐选题（待选）
```dataview
TABLE WITHOUT ID file.link AS 选题, 推荐分, 角度, 来源笔记, file.cday AS 生成于
FROM "40-选题库"
WHERE 状态 = "待选"
SORT 推荐分 DESC, file.ctime DESC
LIMIT 20
```

## 🔥 近 7 天高分对标笔记
```dataview
TABLE WITHOUT ID file.link AS 笔记, 作者, 选题分 AS 分, 超常倍数 AS 倍数, 互动, 标签, choice(拆解, "✓", "") AS 已拆
FROM "20-对标笔记"
WHERE 选题分 >= 50 AND date(最近同步) >= date(today) - dur(7 days)
SORT 选题分 DESC
LIMIT 20
```

## 📈 正在涨的笔记
```dataview
TABLE WITHOUT ID file.link AS 笔记, 作者, 日增互动, 互动, 发布
FROM "20-对标笔记"
WHERE 日增互动 >= 100
SORT 日增互动 DESC
LIMIT 10
```

## 👀 对标账号
```dataview
TABLE WITHOUT ID file.link AS 账号, 粉丝, 粉丝日变化 AS 粉丝变化, 互动中位数, 爆款数, dateformat(date(最近同步), "MM-dd") AS 同步
FROM "10-对标账号"
SORT 粉丝 DESC
```
